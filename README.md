# Sistema Etork (Novo)

Projeto reiniciado com foco apenas no formato visual mostrado nas imagens de referencia.

## O que foi mantido

- Logo da Etork
- Fundo e estilo geral escuro do layout
- Estrutura visual das telas principais

## O que foi removido

- Autenticacao
- Rotas antigas
- Backend Supabase
- Contextos e modulos do portal anterior

## Telas implementadas

- Splash com logo Etork Brasil
- Splash "SISTEMA ETORK"
- Servicos (dashboard)
- Novo orcamento
- Novo agendamento
- Nova venda
- Imprimir recibo

## Execucao

```bash
npm install
npm run dev
```

Build de producao:

```bash
npm run build
```

## Observacao

Os dados estao mockados para reproduzir o visual e o fluxo das telas. O projeto esta pronto para receber integracao com API/backend novo quando voce decidir o novo dominio/repositorio.
